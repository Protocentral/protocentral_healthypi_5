# Archived

The contents of this directory are **no longer maintained** and are kept only for reference.

| Folder | What it was | What to use instead |
| ------ | ----------- | ------------------- |
| `gui/` | Processing sketch that plotted the HealthyPi 5 serial stream, plus the Raspberry Pi boot-config files used to run it on a Pi | [OpenView](https://github.com/Protocentral/protocentral_openview) |
| `python/` | Standalone Python serial-reader and LabStreamingLayer (LSL) streaming scripts | [OpenView](https://github.com/Protocentral/protocentral_openview), or the packet format in the [firmware repository](https://github.com/Protocentral/protocentral_healthypi_5_firmware) if you are writing your own client |

These are unlikely to build or run against current firmware without changes. Pull requests against this directory are not accepted.
